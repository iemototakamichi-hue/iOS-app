# BorrowBack - iOS Application

## Overview
BorrowBack is an iOS application developed using Swift and Xcode as part of a university programming project.

The application is designed to help users manage borrowed and lent items.

## Technologies
- Swift
- Xcode
- UIKit
- Storyboard

## Main Features
- Register borrowed and lent items
- View a list of borrowing and lending records
- Check detailed information about each record
- Manage borrowing and lending information
- Notification management

## Purpose
This project was developed to gain practical experience in iOS application development, including user interface design, screen navigation, and data management.
